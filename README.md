# 遇见集

> 把散落在相册里的风景与偶遇，整理成有地点、有故事、可以继续探索的地图手帐。

遇见集是一款面向户外与旅行爱好者的 **AI 旅行记录 Agent**。它能够理解旅途中拍摄的图片及其上下文，自动生成带有地点、故事与自然知识的「遇见记录」，并将一段旅程中的多次遇见串联起来，沉淀为可回看、可探索、可分享的个人旅行博物志。

## 产品简介

旅行结束后，照片往往散落在相册中：我们记得画面，却逐渐忘记它发生在哪里、遇见了什么，以及当时为什么想按下快门。

遇见集希望让每一次记录不止停留在照片本身：

1. 用户上传或拍摄旅途中的图片，并补充原话、语音、地点或定位信息；
2. AI 理解画面与上下文，识别当地风物、自然知识和旅途线索；
3. 系统生成一页结构化的「遇见记录」，保留故事与判断依据；
4. 用户可以围绕记录继续向 AI 提问，让 AI 成为一路陪伴、一起发现的旅行搭子；
5. 多条记录最终汇聚为地图足迹与旅程合集，方便回顾和讲述。

## 已实现功能

当前仓库为移动端 Web MVP，已经支持：

- **创建遇见**：上传或拍摄图片，补充原话、语音、地点及定位信息；
- **AI 图片理解**：由视觉模型识别内容并生成分类、介绍、趣闻与判断依据；
- **遇见关系判断**：根据历史记录判断本次内容属于「初见」还是「重逢」；
- **记录详情与追问**：在详情页查看完整内容，并围绕当前记录继续向 AI 提问；
- **个人旅行博物志**：沉淀和浏览旅途中记录的自然、人文与偶遇内容；
- **世界地图足迹**：在世界地图中查看记录分布与旅行足迹；
- **旅程总结**：按时间范围聚合多条记录，由 AI 生成阶段性旅程总结；
- **本地数据存储**：照片与记录默认保存在浏览器 IndexedDB 中；
- **分享卡生成**：通过浏览器 Canvas 生成 `1080 × 1920` 竖版分享卡。

## 核心页面

| 路由 | 页面说明 |
| --- | --- |
| `/` | 世界地图与旅行足迹 |
| `/encounter` | 新建遇见记录 |
| `/item/[id]` | 遇见记录详情与 AI 追问 |
| `/firsts` | 旅程合集与阶段性总结 |

服务端接口集中在 `src/app/api`，主要负责图片识别、地图数据聚合与旅程总结。

## 本地运行

### 1. 安装依赖

```bash
npm install
```

### 2. 配置环境变量

复制环境变量示例文件：

```bash
cp .env.example .env.local
```

在 `.env.local` 中配置阿里云百炼 API：

```dotenv
DASHSCOPE_API_KEY=你的百炼APIKey
DASHSCOPE_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
VISION_MODEL=qwen3-vl-plus
```

请勿将包含真实密钥的 `.env.local` 提交到 Git 仓库。

### 3. 启动开发环境

```bash
npm run dev
```

启动后，在浏览器中访问终端提示的本地地址即可使用。

## 数据与隐私说明

- 照片和遇见记录默认仅保存在用户当前浏览器的 IndexedDB 中；
- 进行 AI 识别时，图片会临时发送至所配置的模型服务；
- 应用服务端不保存用户上传的原始图片；
- 清理浏览器数据或更换设备可能导致本地记录丢失；
- AI 生成的物种、地点、自然知识及其他内容可能存在误差，请结合实际情况核实。

## 项目状态

遇见集目前处于 **MVP 持续迭代阶段**。现阶段重点是验证从「旅途素材」到「遇见记录」，再到「地图足迹与旅程总结」的核心体验闭环。

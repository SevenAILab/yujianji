# 遇见集 UI 风格准则

> 版本：0.1 · 用途：后续风格页与窗口改造的执行规范
>
> 当前落地参考：`/style-lab`。这是一套「只换视觉语言、不改信息架构」的规则。

## 1. 设计定位

遇见集不是科技仪表盘，也不是传统旅行相册。它应该像一张正在生成的精神地图：温暖的纸面承载记忆，靛蓝负责叙事，鼠尾草绿和珊瑚红标记行动与状态。

视觉融合约束：

- Kenya Hara 式留白：底色温和、信息不拥挤，不用装饰填满空白。
- Pentagram 式编辑网格：标题、按钮、统计和窗口边缘必须有明确的对齐关系。
- 参考 UMC 产品界面的模块语言：无通用卡片边框，使用错位色块、45° 斜切和窗口形状建立层级。

最重要的原则：先保留原有内容结构，再换颜色、字体、形状和空间关系。不要为了视觉探索重新发明信息架构。

## 2. 固定色板

以下颜色是本风格的唯一主色，不要临时添加相近色。

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--ink` | `#1B1715` | 极少量深色文字、底层对比 |
| `--paper` | `#EEE8DA` | 页面主纸面、窗口外部 |
| `--cream` | `#F8F1DD` | 白色内容卡、导入按钮、导航 |
| `--indigo` | `#454471` | 品牌主色、标题、CTA、数字 |
| `--moss` | `#8B9C7E` | 拍摄、地图激活、自然状态 |
| `--coral` | `#EF655F` | 录音、进行中、提醒状态 |

探索页外部背景只允许使用低对比中性渐变：`#AEB3B6 → #C3C3BA → #D0C2B1`。不要使用霓虹、纯黑大面积背景或深蓝科技渐变。

## 3. 字体与字号

### 字体角色

- 中文标题、正文、按钮标签：`var(--serif)`，即 `Noto Serif SC / Songti SC / STSong / Georgia`。
- 英文副标题、状态码、元信息：`Arial / Helvetica Neue`，使用大写和字距制造编辑感。
- 数字统计：`Arial / Helvetica Neue`，粗体；数字是数据锚点，不使用衬线数字。

### 五级字号上限

页面最多保留五层字号，不再额外创造 16px、18px、20px 等中间层。

| 层级 | 桌面 | 移动 | 用途 |
| --- | ---: | ---: | --- |
| Display | 42px | 35px | 遇见集字标 |
| Title | 28px | 23px | 统计数字、页面主标题 |
| Body | 17px | 14px | 副标题、核心叙事 |
| Label | 13px | 11px | 按钮、文字入口 |
| Caption | 10px | 10px | 英文、地点、时间、操作提示 |

字号之外只用字重和颜色区分层级，不再通过大量阴影、描边、下划线制造层级。

## 4. 几何规则：所有斜角均为 45°

斜切必须使用相等的横向和纵向位移，禁止用无法控制角度的百分比斜边。

```css
--cut: 12px; /* 小按钮 */
--cut: 22px; /* 导航 */
--cut: 34px; /* 大窗口 */
```

### 默认异形按钮：右上 + 左下

适用于进入图景、录音、导入等常规模块：

```css
clip-path: polygon(
  0 0, calc(100% - var(--cut)) 0, 100% var(--cut),
  100% 100%, var(--cut) 100%, 0 calc(100% - var(--cut))
);
```

### 拍摄按钮：左上 + 右下

拍摄按钮使用镜像方向，形成与录音、导入的识别差异：

```css
clip-path: polygon(
  var(--cut) 0, 100% 0, 100% calc(100% - var(--cut)),
  calc(100% - var(--cut)) 100%, 0 100%, 0 var(--cut)
);
```

### 底部导航：只切上方左右

底部导航的底边必须完整水平，不切底角：

```css
clip-path: polygon(
  var(--cut) 0, calc(100% - var(--cut)) 0,
  100% var(--cut), 100% 100%, 0 100%, 0 var(--cut)
);
```

## 5. 窗口与页面结构

### 地球窗口

地球窗口保持原有内容结构：提示语 → 地球 → 拍摄/录音/导入 → 文字入口 → 四项统计 → 记录提示。

窗口不使用黑色描边、不使用圆角卡片边框。使用暖白填充和上方错位肩部建立轮廓：

```css
.globeStage {
  --cut: 34px;
  background: #F7F4EB;
  clip-path: polygon(
    0 0,
    calc(58% - var(--cut)) 0,
    58% var(--cut),
    calc(100% - var(--cut)) var(--cut),
    100% calc(var(--cut) * 2),
    100% 100%,
    0 100%
  );
}
```

窗口底边必须水平。顶部两个斜切点负责对齐：右端对应副标题末尾，窗口宽度和按钮位置变化时要重新检查，不要凭感觉调百分比。

### 地球描线

共享 `MemoryGlobe` 不改色；风格页只在 canvas 外层做主题映射。主题色应该是低饱和靛蓝，不要变成高亮紫或荧光蓝：

```css
.globeStage canvas {
  filter: hue-rotate(52deg) saturate(1.18) brightness(.86);
}
```

## 6. 操作按钮

顺序固定为：拍摄 → 录音 → 导入。位置和语义不可因为换风格而改变。

| 操作 | 背景 | 斜切方向 |
| --- | --- | --- |
| 拍摄 | `--moss` | 左上 + 右下 |
| 录音 | `--coral` | 右上 + 左下 |
| 导入 | `--cream` | 右上 + 左下 |

按钮不使用圆角、厚边框或大面积阴影。图标使用 Lucide，线宽保持 `1.7–1.9`；中文标签使用衬线体粗体。

## 7. 统计、文字入口与导航

- 四项统计仍然是「已遇见 / 第一次 / 国家 / 地点」，只用留白和字号建立层级，不使用分隔线。
- 「没有照片？写几句也行」保持居中、衬线、轻下划线；不要包成按钮。
- 主导航固定三项：旅途 / 地图 / 我的。导航背景使用 `--cream`，只切上方左右，底边水平。
- 当前页激活图标使用 `--moss` 圆形底；不要给整个导航项加胶囊背景。

## 8. 间距与响应式

- 主要间距遵循 8pt 节奏：`8 / 16 / 24 / 32 / 48`。
- 大窗口左右不要额外加一圈边框；页面外部的中性灰只作为留白衬托。
- 移动端不改变内容顺序，只缩小字号、窗口高度和 `--cut`；按钮仍保持 45°。
- 任何新窗口必须先在 560px 宽桌面预览和 390px 左右移动预览各看一次。

## 9. 禁止事项

- 不重新设计原页面的信息架构。
- 不把用户画的黑色参考线直接做成成品线条；黑线只是几何示意。
- 不使用圆角矩形替代异形窗口。
- 不混用 30°、60° 和 45° 斜角。
- 不新增第五种主色，不使用发光、渐变霓虹和深蓝科技背景。
- 不为装饰添加细分隔线、厚描边或无意义阴影。

## 10. 后续改造检查清单

每次改其他窗口前，按下面顺序自检：

1. 内容结构是否和原页面一致？
2. 是否只使用本准则中的六个主色？
3. 所有斜边是否通过等距像素值实现 45°？
4. 窗口底边是否水平？
5. 按钮顺序、颜色、斜切方向是否符合第 6 节？
6. 是否误加了黑色示意线、圆角卡片或细分隔线？
7. 560px 和移动宽度下，标题、按钮、统计是否仍然对齐？

# Insta360 X6 设备准备说明

## 文件用途
- `Insta360X6FW-25C41E6FENC-1.1.7-user.bin`：X6 相机固件更新文件，用于保证相机 OSC 功能和拍摄稳定性。请通过 Insta360 官方更新流程刷入相机，不要提交到网页仓库。
- `Insta360_Reframe_For_Adobe_Premiere_6.0.4(RC_build16)_20260827_212330_1787837170119.exe`：Adobe Premiere 重取景插件，用于电脑端导入和编辑 360° INSV/MP4。请使用默认安装路径，避免 Premiere 找不到插件。

## 网页控制相机流程
1. 使用官方方式确认 X6 已安装最新固件。
2. 在 X6 上开启 WiFi 热点。
3. 手机 WiFi 连接到 X6 热点，默认相机地址为 `http://192.168.42.1`。
4. 打开遇见集 `/devices` 页面。
5. 使用「状态」确认相机在线。
6. 使用「拍摄」「录像」「停止」直接触发快门和录像。
7. 使用「文件」读取最新文件，并进入 `/encounter` 显影。

## 说明
- 网页端通过 OSC HTTP JSON 协议控制相机，不依赖影石官方 App、蓝牙或语音。
- 固件和 Premiere 插件只负责设备端/后期端，不需要嵌入遇见集应用。
- 演示前请确保相机电量充足、热点稳定，并提前完成一次拍摄/录像验证。

## 限制
- OSC 协议不支持实时预览流，只能触发拍摄、录像、读取状态和拉取文件。
- 固件文件不能嵌入遇见集网页，也无法由浏览器直接执行；必须先通过官方流程刷入相机。
- 如需实时预览流，需要影石官方 SDK/App 接口，不属于当前 OSC 方案范围。
